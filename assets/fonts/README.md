# Шрифты сайта

Файлы лежат локально, чтобы у сайта не было внешних запросов: ни Google Fonts,
ни любого другого CDN. Сеть при загрузке страницы не нужна вовсе.

## Что здесь

| Файл | Гарнитура | Подмножество | Вес |
|---|---|---|---|
| `inter-var-cyrillic.woff2` | Inter | кириллица | вариативный, 400–800 |
| `inter-var-latin.woff2` | Inter | латиница | вариативный, 400–800 |
| `jbm-var-cyrillic.woff2` | JetBrains Mono | кириллица | вариативный |
| `jbm-var-latin.woff2` | JetBrains Mono | латиница | вариативный |

Подмножества разделены по `unicode-range` в `@font-face` — браузер подтягивает только те,
что нужны для текста страницы. Греческое, вьетнамское и расширенные подмножества не брались:
сайт русский, а вся нужная типографика (тире `—`, кавычки `«»`, средняя точка `·`, многоточие)
попадает в подмножество `latin`.

Оба шрифта отдаются как **вариативные**: Google Fonts возвращает один и тот же файл
на разные запрошенные веса, поэтому `jbm-var-*` объявлен диапазоном, а не двумя файлами.
Итого 112 КБ вместо 278 КБ, которые получились бы при скачивании всех подмножеств.

Обе лицензии разрешают использование в личных и коммерческих проектах, включая
размещение на сайте и в фирменных материалах. Ограничение OFL касается перепродажи
файла шрифта, а не набранного им текста. Системный стек в `font-family` оставлен
как запасной — это требованиями бренда допускается.

Источник файлов — Google Fonts (fonts.googleapis.com), загружены 15.09.2026.

## Как обновлять

Подмножества забираются по подписи современного браузера, иначе отдаётся устаревший
формат. Запрос и разбор — в истории задачи; ключевое: указывать `User-Agent` Chrome,
иначе вместо `woff2` придут `.ttf`. После замены файлов проверить, что `unicode-range`
в `@font-face` внутри `index.html` соответствует новому CSS от Google.

# shitov.su — личный сайт Andrey.Shitov

Статический одностраничник без бэкенда. Хостинг — GitHub Pages, домен `shitov.su`
(файл `CNAME`). Сборки нет: `index.html` открывается как есть.

## Структура

```
index.html   вся страница: разметка, стили и скрипты в одном файле
assets/      photo.jpg, og.jpg, favicon.svg, favicon-32.png, favicon-16.png,
             apple-touch-icon-180.png, og-lockup.svg (исходник для og.jpg)
assets/fonts/ Inter и JetBrains Mono (woff2, кириллица + латиница) — см. README там же
certs/       сканы документов об образовании (1600 px, до 500 КБ)
CNAME        кастомный домен для GitHub Pages
```

## Разделы

Hero · Обо мне · Стек · Проекты · Образование · YouTube · Для HR · Контакты

## Как править контент

Проекты и документы лежат в двух массивах в конце `index.html`:

- `const projects` — карточки раздела «Проекты». Поля: `cat` (фильтр), `org`, `title`,
  `short` (текст карточки), `desc`, `role`, `year`, `res` (измеримый результат),
  `list` (что сделано), `tags`.
- `const credentials` — карточки раздела «Образование». Поля: `type` (`diploma` / `cert`
  / `award`), `title`, `issuer`, `year`, `note`, `file` (путь к скану),
  `verify` (ссылка на проверку подлинности, необязательно).

## Фирменный стиль

Оформление подчинено палитре «Малахит» (hue 165° в OKLCH, основной `#00976d`) из пакета
фирменного стиля. Знак — «Открытый шеврон»: шеврон и отдельная полоса-основание под ним.
Герб (`mark-shield.svg`) применяется только в разделе «Для HR».

Токены — **два** блока в начале `index.html`: `:root` (светлая тема, она же по умолчанию)
и `[data-theme="dark"]`. Правьте токен, а не отдельные правила.

```css
:root{
  --brand-50 … --brand-950   брендовая шкала
  --n-0 … --n-1000           нейтрали с зелёным подтоном
  --dg-*                     шесть категорий: карточки слоёв, типы документов, схемы
  /* роли: имена, которыми пользуются правила ниже по файлу */
  --brand --brand-deep --brand-soft --brand-fill --brand-ink --on-brand
  --ink-accent --on-accent --btn-a --btn-b --grad-a --grad-b --grad-c
  --s1 … --s6  --cover1 … --cover4  --avatar
  --bg --bg-2 --surface --surface-2 --text --muted --line --shadow --radius --nav-h --mx --my
}
[data-theme="dark"]{ /* переопределяет всё, что должно темнеть */ }
```

`--s1…--s6` ссылаются на `--dg-*`, поэтому в тёмной теме категории меняются сами.
`--grad-a/b/c` работают через `background-clip:text` (слово «сама» в заголовке и цифры
статистики) — **в тёмной теме они обязаны светлеть**, иначе текст исчезает на фоне.

Вендорские гаммы (openSUSE, Red Hat) из проекта **удалены осознанно**: фирменный стиль
запрещает использовать чужие палитры как элементы личного бренда, а зелёный намеренно
сдвинут с 133° на 165°, чтобы знак не читался как «канал про Red Hat».

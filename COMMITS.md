# Формат коммитов

Договорённость от 26.08.2026.

## Правило

Сообщение коммита — **одна строка**. В ней перечисляются только **имена блоков**,
которых коснулись правки. Что именно менялось внутри блока — не пишем.

```
Добавлено: <блоки>. Изменено: <блоки>. Удалено: <блоки>.
```

Используются только те части, которые применимы. Имена блоков — через запятую.

## Примеры

```
Изменено: Первый экран, Проекты.
```

```
Добавлено: YouTube. Удалено: Схемы, Курсы.
```

```
Добавлено: Документация.
```

## Имена блоков

Разделы страницы:

- Первый экран
- Обо мне
- Стек
- Проекты
- Образование
- YouTube
- Для HR
- Контакты

Сквозные элементы:

- Шапка
- Подвал
- Мета-теги
- Модалка проекта
- Просмотрщик сканов

Прочее:

- Ассеты — файлы в `assets/` и `certs/`
- Документация — README.md, COMMITS.md
- Инфраструктура — CNAME, .gitignore, настройки репозитория

Новый блок добавляется в этот список вместе с первым коммитом, который его создаёт.

## Что остаётся в сообщении кроме строки

Только трейлер соавторства — он не является описанием правок:

```
Co-Authored-By: Claude Opus 5 <noreply@anthropic.com>
```

Тело коммита не заполняется.

## Область действия

Правило распространяется на все коммиты начиная с 26.08.2026.
Более ранние коммиты переписывать не нужно.
